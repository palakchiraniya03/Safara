# Safara – ML-Powered Safe Route Recommendation System

## Overview

Safara is a full-stack geospatial analytics platform that recommends safer travel routes using crime hotspot detection and route risk assessment.

The system combines machine learning, geospatial visualization, and route planning to help users identify safer travel paths and nearby emergency resources.

---

## Key Features

* DBSCAN-based crime hotspot detection
* ML-powered crime analytics dashboard
* Safe route recommendation and comparison
* Route risk assessment based on crime density
* Nearby hospital and police station discovery
* Interactive map visualization using Leaflet
* Flask REST API backend
